Step 2: Install Git for Windows (Essential)

AI agents run terminal commands to test and build software. Windows default command lines (CMD/PowerShell) often fail with AI syntax. Git provides Git Bash, which guarantees seamless execution.

  1. Download the 64-bit Git for Windows installer.
  2. Click Next through the setup prompts (the default selections are recommended).

2 Phase 2: One-Time Configuration

Step 3: Set Git Bash as Default Terminal

Configure VS Code to use Git Bash by default so the agent doesn't run into PowerShell permission errors.

  1. Open Visual Studio Code.
  2. Press Ctrl + Shift + P to open the Command Palette.
  3. Type: Terminal: Select Default Profile and hit Enter.
  4. Select Git Bash from the list.
Command Palette Input
Terminal: Select Default Profile

3 Phase 3: Your "Hello World" Project

🛑
The Golden Rule of AI Agents:
Always open a project folder first! An AI coding agent cannot create files or track Git checkpoints if VS Code is opened on an empty/unsaved window.
Step 6: Create & Open a Folder
  1. Create a new empty folder anywhere on your computer (e.g., on your Desktop named ai-hello-world).

  3. Select your ai-hello-world folder.

? Troubleshooting & FAQs

Error: "Could not find ripgrep binary" or agent freezes on start ▼

Cause: VS Code recently relocated its internal search binary, or the terminal environment wasn't reloaded after installation.

Fix:

  1. Close Visual Studio Code completely.
  2. Reopen VS Code from your Windows Start Menu.
  3. Open your project folder (File $\rightarrow$ Open Folder...).
  4. Click the + (New Task) button at the top of the Roo Code panel to start clean.
Error: "No existing API conversation history" or resume task fails ▼

Cause: If a task was interrupted or failed before sending its first message, there is no conversation history on disk to resume.

Fix: Never click "Resume Task" on a broken/aborted task. Always click the + (New Task) icon at the top of Roo Code to start fresh.

Error: "Authentication Fails" or Invalid API Key ▼

Fix:

  1. Click the Settings (⚙️) icon at the top of the Roo Code panel.
  2. Clear the API key field completely.
  3. Copy your DeepSeek key directly from platform.deepseek.com.
  4. Paste it back in, ensuring there are no accidental spaces before or after the key.
  5. Ensure the key begins with sk-.
Error: "Insufficient Balance" (HTTP 402) ▼

Cause: The DeepSeek API is prepaid. If your balance is \$0.00, it cannot generate completions.

Fix: Log in to platform.deepseek.com $\rightarrow$ Top up $\rightarrow$ add \$2 to \$5. DeepSeek is extremely cheap, and a small deposit typically lasts for weeks of heavy development.

What is the difference between "Architect Mode" and "Code Mode"? ▼

Architect Mode (Planning): The AI reads your files, investigates dependencies, and creates an implementation plan without touching your code. Use this when planning a new feature or refactoring.

Code Mode (Execution): The AI writes code, creates files, and runs terminal commands. Use this when you are ready to build.

💡 Best Practice: Start complex requests in Architect Mode first, review the plan, and then switch to Code Mode to implement it.

How do I undo a change if the AI breaks something? ▼

Roo Code automatically creates a shadow Git checkpoint before every action.

To undo: Look at the bottom of the task conversation in the Roo Code panel. You will see checkpoint timestamps (e.g. "Checkpoint created 2m ago"). Click the checkpoint button to restore your project files back to that exact second.

How do I enable auto-approvals so I don't have to click "Approve" for every file? ▼

In Roo Code Settings (⚙️), scroll down to Auto-Approval Settings:

  • ☑️ Always approve read-only operations (Safe — reading files, searching code)
  • ☑️ Always approve file writes (Convenient — automatically applies edits)
  • ⚠️ Keep "Execute terminal commands" manual until you are familiar with the tool.
